Migracion Robiotec a Django + DRF + Celery + TypeScript
Fecha de inicio: 2026-07-01

Objetivo
- Reconstruir la plataforma sobre Django como backend principal.
- Usar Django REST Framework para APIs.
- Usar PostgreSQL como base de datos principal.
- Usar Celery + Redis para tareas pesadas y programadas.
- Mantener Bootstrap como lenguaje visual.
- Pasar el frontend a TypeScript modular con componentes compartidos.
- Mantener IA, streaming, GPS, drones, RBox y monitoreo como procesos independientes comunicados por REST.
- No tocar ni refactorizar faces_gallery en esta fase.

Decision operativa
- No usaremos Docker como base de produccion.
- Los procesos se manejaran con systemd, igual que los servicios actuales.
- La nueva plataforma se crea en paralelo para no romper apicentral/dashboard actuales.
